Artist Created Stylish Arcane-Inspired FPS Set in Zaun Using UE5

#News#Unreal Engine#Video Games

Check out this incredible project created in the style of Fortiche's Arcane.

If you are an Arcane fan, make sure to check out this amazing project by 3D Environment Artist Stephen Chin – a fan game inspired by the beloved universe.

The goal was to place the player in a world inspired by Fortiche's animated series. This FPS is set in the industrial environments of Zaun, created with vibrant stylized graphics using Unreal Engine 5. The project took the creator five months. According to the description on social media, the game is not distributed, and we can check it out only through concept images and videos.
