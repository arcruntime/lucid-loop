Use the explicit `stageOnly` list in `staging-manifest.json`, plus that manifest and this file. It covers the project-owned Tokon shaders/metas, category preset, original/refined facial maps, selected cap G map, four map-bake scripts, and curated V2/V3 actual GPU evidence with exact compiled source snapshots. Shader mirror checks must all match the tested hashes before committing.

This is a diagnostic checkpoint. Root selected the refined face response and placed cap mask as provisional baselines; source eye geometry is still rejected. Main H/Tokon scenes and generated character assets are deliberately outside this checkpoint. Outline work is also separate and still undergoing actual GPU proof.

The evidence is reproducible as a hash-bound record of exact inputs and outputs, but this minimal package does not itself rebuild the historical H player from a fresh checkout. The manifest lists the already tracked runtime/version dependencies and the separately untracked H FBX/contracts. The actual generated source scene, mapped H materials/textures, video/timeline, original artist reference and pipeline remain in the authorized scratch project. Rebuilding a player requires that separate H preparation package; do not describe this shader checkpoint as a standalone runnable scene.
