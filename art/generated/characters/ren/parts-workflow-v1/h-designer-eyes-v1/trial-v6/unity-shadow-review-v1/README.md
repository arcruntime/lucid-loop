# Received-shadow isolation on neutral v6

Fourteen actual D3D11 player captures compare the unchanged neutral v6 head/eyes with baseline receiving versus `_ShadowStrength=0` and `_FaceCastShadowStrength=0` on only three head material slots and two skin shutters. All other geometry, pigment, material controls, lights and cameras stay fixed. Per-slot runtime readbacks are in `ShadowLiveEvidence.json`.

Baseline neutral front/quarter are pixel-identical to the frozen first neutral review. The unlit pair is also pixel-identical. The broad mask-like band is reduced without received attenuation, but a residual boundary remains; this is a cause-isolation experiment, not a selected shading fix. All20 graphic eye renderers already have shadow casting disabled; only the two shutters cast. A subsequent shutter-caster-only comparison will restore normal receiving and leave head/cap/hair casters unchanged.

The source portrait comparison now imports the exact original image bytes with NPOT=None, preserving1536x1024. It samples the same source-pixel rectangle x275/y25/width430/height400 from both the fixed source-camera render and original sketch, displayed uniformly2x. No independent XY warp or model camera change was used. The existing approximately18pixel mouth/chin camera-fit residual and different mouth pose remain visible. Full original reference remains in the viewer; flawed first full-sheet pairs remain in the earlier frozen package.

`shadow-baseline--source-portrait-paired.png` is a useful direct comparison and still exposes substantial likeness/paint differences. The result is not artist acceptance.
