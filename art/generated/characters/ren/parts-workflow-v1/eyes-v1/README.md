# Ren native P2 eyes

The current integration candidate is [lid-repair-v2](lid-repair-v2/README.md). The first `Ren_P2_Eyes_Neutral.blend` in this directory is a preserved neutral-only checkpoint, not the final blink construction.

The native main head has recessed socket backing, not two complete open boundary loops. Removing the three large disconnected eye components and 56 lash components reveals usable elongated apertures. Front rays place the backing approximately 0.04–0.05 source units behind the eye front. These are normalized source coordinates, not physical meters.

The first checkpoint places separate sclera, grey-blue iris, graphic liner and lash components inside those apertures. All retained native positions are preserved. Separate shutter surfaces demonstrate interpolation, but the native upper lid roll leaves a conspicuous fixed outline during closure; four outer-corner sclera samples remain visible. That blink is rejected. The later local topology repair replaces the defective socket/lid disks while retaining exact healthy peripheral anchors.

Inspection images `native-main-only-front.png` and `native-main-only-quarter.png` show the native sockets without the generated eye/lash components. All vendor originals remain immutable.
