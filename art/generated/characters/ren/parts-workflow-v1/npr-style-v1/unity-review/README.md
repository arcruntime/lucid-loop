# Actual Unity NPR comparison

This is a technical shading study on the frozen P2 complete-head V2 prototype. Root reviewed the soft-shadow quarter view and found the pipeline correction visible. **The P2 likeness and baked lip paint remain rejected; this is not aesthetic approval.** The selected Studio H cheeks/jaw source is not represented by these meshes.

Open `Assets/CharacterArt/Generated/Preview/Scenes/RenNprReview.unity` and enter Play mode. The left panel uses the old diffuse shader and the right uses the new NPR shader; both share the exact geometry, source colors, pose, camera framing and control values. The untouched original artist sheet is visible by default. The separate Windows viewer is `.local/ren-npr-review-v1-final/RenNprReview.exe`; it has not been launched visibly.

The 28 files in [live/](live/) are actual camera renders from the running D3D11 Unity player after at least 12 updates per pose. Start with the paired `rest--front`, `rest--quarter` and `rest--profile` files. `club-a` and `club-b` sample the same moving point-light paths at phases 0 and pi. `partial` combines half blink and diagonal gaze; `full-blink` and `open-A` show the working facial controls. The two `unlit--front` PNGs are byte-identical, demonstrating unchanged source color. The known six hair `capOn` weights remain correct in every capture.

The new scene owns its preview URP asset: main shadows on, 2048 resolution, one cascade, shadow distance 6, Medium soft filtering; additional shadows off. Directional keys use soft shadows, depth/normal bias 0.025 and near plane 0.05. The old diffuse baseline has no shadow caster or shadow receiving. No source texture, jaw, hair mesh or shape key was edited for this comparison. Earlier flat-preset and hard-shadow fallback diagnostics remain under `.local` and are superseded by this evidence.

[RenNprReviewLiveEvidence.json](live/RenNprReviewLiveEvidence.json) binds every PNG hash to source, shader, preset and runtime hashes plus actual controls and pipeline support flags. [RenNprReviewEvidence.json](RenNprReviewEvidence.json) records shared source counts; [verification.json](verification.json) records the final build, exact restoration of the inherited scratch settings, four final-player frames matching this suite byte-for-byte, and a resolved dependency audit. Both main and scratch `GymPipeline.asset` bytes remain unchanged.

[RenNprReviewShaderAudit.json](RenNprReviewShaderAudit.json) reports zero ShaderUtil messages and the expected forward, depth, depth-normal and shadow-caster passes. The headless SRP Batcher probe returns `Not initialized ()` even after synchronous compilation, so batching compatibility is **unverified**. Additional-light shadows, Forward+, Metal, iPhone performance, full speech coverage and final art acceptance are not demonstrated here. A hidden-window backbuffer UI screenshot was black and excluded; the included images are explicit URP GPU camera captures, with no image edits or baked-pose substitution.
