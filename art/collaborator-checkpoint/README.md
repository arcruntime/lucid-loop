# arcruntime checkpoint assets

Selected reusable assets from `codex/btd-checkpoint-one@95aae5d`, contributed by arcruntime. See [the review](../../docs/ARCRUNTIME_REVIEW.md) for integration decisions and limits. `manifest.json` records original/destination paths and file hashes. Assets here are preserved for adaptation, not automatically bundled in the game.

The portrait atlas and backspin are integrated under Unity/Assets/Gyms/Resources. Other images, shaders, music and recorded story lines remain here. The retained `server/src/story-voice.mjs` is the original catalog/generation reference, not a running server or an instruction to regenerate audio. See `docs/LICENSE-AND-PROVENANCE.md` and `docs/ART-PROMPTS.md` for original attribution.
