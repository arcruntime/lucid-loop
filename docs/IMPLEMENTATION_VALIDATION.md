To repeat the audio-device check, set `FIXTURE_PORT=8790` in the relay process environment and start `node src/fixture-cli.mjs` from `server/`, then select **Lucid Loop → Validate audio device PlayMode smoke** in the clean, idle Editor. The fixture otherwise defaults to port 8081. No provider key or microphone permission is needed. The test injects Unity's external-device notification into the actual voice controller and uses the fixture's close handshake; it does not simulate an operating-system interruption or establish iOS AEC quality.
