# Checkpoint two — typed character decisions and music

Local only. Builds on the user-approved checkpoint-one sequence. The existing voice gym and voice relay are unchanged; this stage uses typed conversation and a separate local HTTP service.

## Start

1. Start `tools/start-dialogue.command` in Terminal. It asks for an API key with hidden input only if OPENAI_API_KEY is not already set. The key stays in the server process environment, never in a project file, Unity, or Git. Keep Terminal open. Alternatively, run `npm run dialogue` in server/ with OPENAI_API_KEY exported.
2. Service address: http://127.0.0.1:8082. The server binds only to loopback, rejects browser-origin requests, limits request size/concurrency/rate, and has a 20-second upstream timeout. Health reports configuration only; it does not prove API entitlement.
3. Open the separate mvp-checkpoint/Unity project, scene Assets/Gyms/Scenes/BeforeTheDrop.unity, and press Play. Ensure Unity's Game view audio is not muted. The music toggle is bottom right.

Default dialogue model: gpt-4.1-mini, configurable server-side via BTD_MODEL before starting. Uses the Responses API with strict JSON Schema and store:false. No automatic retry or silent scripted fallback. A successful request incurs normal API usage on the supplied project.

## Playtest

Loop one remains the authored interactive opening. Music starts Aggressive; the track cuts at rewind and restarts from the opening.

On loop two, click a character to approach. Type your own request and press Say it. The panel stays open so you can follow up. End conversation (or Escape) cancels pending requests; a cancelled or late response must not change state.

Try these in your own words:
- Maya: ask her to wait near the entrance and keep her phone away; explain you want a private conversation. She can agree to both, ask a question, or refuse. The panel reports agreed actions.
- Luca: explain that Theo may get physical and ask him to intervene early, calmly, to give everyone space.
- Ren: use the Intimate / Aggressive track buttons. Selection is immediate and needs no API request. An original backspin-style cue overlaps the 1.2-second crossfade; music stays at normal volume in this menu. Other conversations duck the music smoothly.
- Maya: ask her to come with you. Return together toward Theo and observe the outcome.

Success still requires Maya's private/no-recording agreement and Luca's early-intervention agreement, followed by actually resolving the encounter. Music alone and avoiding the encounter never award success. These fixed predicates remain provisional while the AI interprets varied requests to reach them.

Also try an impossible request, a question without an instruction, or addressing the wrong character. The system should not claim unsupported actions. Stop the dialogue server and send a request: an explicit connection error should leave state unchanged and allow retry after restarting it.

## What to judge

Does the reply reflect what you specifically asked? Does Maya actually stay/follow? Are agreed consequences clear? Are replies quick enough, and does the conversation feel characterful rather than like a command parser? Is the musical contrast audible without overwhelming reading? Can you reach the safe ending without exact wording?

## Boundaries

- AI may choose only actions supported for the speaking character; Unity validates the entire action set before applying anything. No model-generated code, new facts, characters, secrets, or direct win/rewind actions.
- The scrollable per-character transcript preserves every successful exchange, including previous loops labelled by loop number. Restart demo clears it. Only the latest 12 messages from the current loop are sent to the NPC, so old-loop transcripts are player memories, not NPC knowledge.
- Client scene state is authoritative in this local prototype; this is not a multiplayer/anti-cheat server.
- Voice, final illustrated close-ups and art, phone build/signing, and a larger mystery remain later milestones.
- Localhost works for Unity on this Mac. An iPhone cannot reach the Mac via its own localhost; secure device connectivity is not configured in this checkpoint.
- Placeholder music is original procedural audio generated by tools/audio/generate_placeholders.py: no third-party samples, no Suno dependency. Replace Aggressive.wav and Intimate.wav in Resources/MvpAudio to swap tracks; Backspin.wav is the short transition cue.
- Automated HTTP fixtures are explicitly test-only and run on 8083 with -btd-fixture. The normal player command never launches them.

API references: https://developers.openai.com/api/docs/guides/structured-outputs and https://developers.openai.com/api/docs/models/gpt-4.1-mini .

## Human-feedback fixes

- Maya and Luca receive only their own character context and agreements, not the future plot or other NPC state. Generic requests do not establish knowledge of an affair or name a troublemaker.
- Theo is explicitly stationary: private conversation means lowered voices at his current location. He must not offer to lead the player to an unimplemented lounge or VIP destination.
- End conversation closes the panel without moving anyone.
- Ren uses two music buttons; no prompt guessing or network wait. Incoming music cues from its start, crossfades under a short backspin-style sound, and continues while this menu is open. Background execution is enabled for this scene; the reported silence on switching windows was not conclusively diagnosed.
- Full transcript scrolls to the newest message and can be scrolled upward; closing/reopening retains it. Earlier-loop messages remain readable but are excluded from model context.
- Restart the dialogue server to load these changes. `/health` should report revision `knowledge-v2`.
